Blue Dots helps people and organisations near each other find each other. Follow this path if you are onboarding participants onto the network as a local organisation. Examples are skilling centres and ITIs (Industrial Training Institutes) on Blue, schools and education NGOs on Yellow, disabled persons' organisations (DPOs) on Purple, tourism bodies on Orange, and government departments on any dot. It explains what aggregators do, how the Aggregator DPG is built, and how to install and configure it.
